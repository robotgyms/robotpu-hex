# robotpu-hex
A repo to save all hex files in robot PU book series

| Folder | Source | Contents |
| --- | --- | --- |
| `coding-camp/` | Robot PU Coding Camp handouts | Session demo programs (01–32). Import any `.hex` into makecode.microbit.org |
| `level1/` | Level_1 textbook | `robotpupro-*.hex` demos (mirror of pxt-robotpu `tutorials/hex/`) |
